ICRISAT Data Hub

A federation-first catalogue of ICRISAT team datasets and external data sources. Teams contribute CSV, Excel, and Word files with no special skills; the pipeline catalogues them automatically; LLMs access everything through the hub's MCP server.

Who this hub is for

Three audiences, three entry points — same catalogue underneath.

Teams contributing data

Drop files into the shared inbox folder or use the upload web page — no special skills, no database, no code. The pipeline reads, profiles, and catalogues automatically, and flags anything it couldn't infer for a quick review.

  • CSV, Excel (.xlsx/.xls), Word (.docx)
  • Optional sidecar .meta.yaml for full metadata
  • Incomplete uploads get a pre-filled review template

Analysts finding data

Browse the catalogue below: search titles, descriptions, column names, tags, and document text; filter by team, type, and status; expand any asset to inspect every sheet's schema before you download anything.

  • Raw catalogue: assets.json
  • Federated pointers: sources.json

LLM agents (MCP)

The hub speaks MCP: agents can discover datasets, inspect schemas, preview and query tables (read-only SQL), and read documents.

  • stdio for local agents; streamable HTTP for the network
  • Tools: list, search, get, preview, query, read, sources, summary

Reproduce

pip install -r requirements.txt
python -m hub.ingest.pipeline --scan   # inbox -> catalogue
python -m hub.pages                    # catalogue -> docs/data/*.json

A GitHub Action re-runs the export automatically whenever the catalogue or YAML pointers change on main.
