Upload channel of the published datasets — the web form, the shared drop folder, or a drop with a metadata sidecar.

How publishing works

Only reviewed, open datasets appear on this public site.

1 · Upload

Sign in to the data hub (any email), drop files and pick a category.

2 · Review

The category's curator checks the description, licence and access level, then publishes or returns it with comments.

3 · Share

Open datasets show here. ICRISAT-only and restricted ones stay in the hub, where owners grant access by email, list, CSV or domain, and others can request it.

Add your data — 3 ways

All three go through the same curator review.

1 · Web upload recommended

Sign in, drag & drop one or more files, choose a category and fill a short form. Open the upload page ↗

2 · Script / API automation

Create a personal API token in the hub and POST /upload with curl, R or Python.

3 · Drop folder ICRISAT network

Copy files into the shared inbox with a name.meta.yaml (category, owner_email, licence…) to go straight to review.

Federated sources
