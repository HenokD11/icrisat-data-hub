Add your data — 3 ways

No special skills needed for any of them.

1 · Drop folder zero effort

Copy the file into the shared data/inbox/ folder. The pipeline picks it up automatically, infers what it can, and flags gaps for review.

2 · Web page 30 seconds

Drag & drop on the upload page and optionally fill five small fields (team, name, description, tags, contact).

3 · Sidecar metadata fully documented

Drop a tiny myfile.meta.yaml next to the data file and the asset is published immediately, no review round-trip.
